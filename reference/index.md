# Package index

## Package Datasets

Mock data to help you get started

- [`mock_credit`](https://ketchbrookanalytics.github.io/migrate/reference/mock_credit.md)
  : Mock dataset containing credit statistics by customer at two time
  intervals. Some customers only exist in one time interval (they either
  became a customer after the first time interval, or discontinued being
  a customer before the second time interval).
